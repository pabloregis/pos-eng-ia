# Mapa de aulas

Este documento complementa a grade curricular oficial com os nomes das aulas apresentados na plataforma do curso e usados nos projetos deste repositório.

O PPC não contém essa divisão por módulo e aula. Registre aqui somente informações fornecidas pela plataforma ou pelo responsável pelo repositório; não derive títulos de aula a partir da ementa ou dos conteúdos programáticos.
