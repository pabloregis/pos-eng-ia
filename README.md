# Projetos da pós-graduação em Engenharia de IA

Este repositório reúne os projetos, exemplos e exercícios desenvolvidos ao longo da pós-graduação em Engenharia de IA Aplicada da UNIPDS.

As pastas estão organizadas por módulo, disciplina e aula, acompanhando a evolução prática dos conteúdos do curso. Entre os temas abordados estão LLMs, APIs de IA generativa, prompt engineering, agentes autônomos, RAG, MCP, arquitetura de sistemas com IA e aplicações de IA em produção.

Para conhecer a pós-graduação, consulte a [página oficial da UNIPDS](https://unipds.com.br/ff-pos-ia/).
