Tensores são estruturas de dados usadas pelo TensorFlow.js para representar informações numéricas que serão processadas por algoritmos de machine learning. De forma simples, eles podem ser entendidos como vetores ou listas de números.

O TensorFlow.js não entende diretamente objetos JavaScript ou valores como textos. Por isso, dados como `"azul"`, `"São Paulo"` ou objetos de pessoas precisam ser convertidos para números antes de serem usados em um modelo.

Por exemplo, considere este array de pessoas:

```js
const pessoas = [
  { nome: "Erick", idade: 30, cor: "azul", localizacao: "São Paulo" },
  { nome: "Ana", idade: 25, cor: "vermelho", localizacao: "Rio" },
  { nome: "Carlos", idade: 40, cor: "verde", localizacao: "Curitiba" }
];
```

A propriedade `cor` contém texto, então podemos transformá-la em uma tabela numérica. Como existem três cores possíveis — azul, vermelho e verde — cada cor pode ocupar uma posição:

| Pessoa | Azul | Vermelho | Verde |
|---|---:|---:|---:|
| Erick | 1 | 0 | 0 |
| Ana | 0 | 1 | 0 |
| Carlos | 0 | 0 | 1 |

Em JavaScript, essa representação poderia ser uma lista de listas numéricas:

```js
const coresComoNumeros = [
  [1, 0, 0], // Erick: azul
  [0, 1, 0], // Ana: vermelho
  [0, 0, 1]  // Carlos: verde
];
```

Essa estrutura contém apenas números e pode ser usada como base para um Tensor. A ideia é parecida com traduzir informações humanas, como cores e categorias, para uma linguagem que o modelo consiga processar: números.
