Normalização de dados é o processo de transformar informações em um formato que o modelo consegue interpretar corretamente. Em problemas de classificação, isso pode significar converter categorias textuais em valores que a rede neural possa usar.

Por exemplo, no contexto temos as categorias:

```js
const categorias = ["premium", "medium", "basico"];
```

Uma rede neural não entende diretamente os textos `"premium"`, `"medium"` ou `"basico"`. Por isso, é necessário normalizar ou codificar essas categorias para uma representação numérica adequada.

Isso é necessário porque o modelo trabalha fazendo cálculos entre os dados de entrada, as conexões e os neurônios das camadas. Ao final, a camada de saída transforma o que foi aprendido em probabilidades para cada categoria, como:

- 78% de chance de ser **Premium**
- 12% de chance de ser **Medium**
- 10% de chance de ser **Basic**

Assim, a normalização ajuda a garantir que os dados estejam organizados de uma forma compatível com os cálculos da rede. É como traduzir os dados para uma “linguagem numérica” que o modelo consegue processar para aprender padrões e decidir qual categoria é mais provável.
