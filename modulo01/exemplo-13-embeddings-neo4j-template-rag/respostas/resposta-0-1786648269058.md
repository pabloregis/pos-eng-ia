Tensores são estruturas de dados usadas pelo TensorFlow.js para representar informações numéricas que serão processadas por algoritmos de machine learning. De forma simples, eles podem ser entendidos como vetores ou listas de números.

O TensorFlow.js não entende diretamente objetos JavaScript nem valores como textos. Por isso, antes de usar dados em um modelo, é necessário convertê-los para uma estrutura formada apenas por números: um Tensor.

Por exemplo, considere este array de pessoas:

```js
const pessoas = [ 
  { nome: "Erick", idade: 30, cor: "azul", localizacao: "São Paulo" }, 
  { nome: "Ana", idade: 25, cor: "vermelho", localizacao: "Rio" }, 
  { nome: "Carlos", idade: 40, cor: "verde", localizacao: "Curitiba" } 
];
```

A propriedade `cor` contém texto, mas o TensorFlow.js precisa de números. Uma forma de representar as cores é criar uma coluna para cada cor possível e marcar com `1` a cor da pessoa, deixando `0` nas demais:

| Pessoa | Azul | Vermelho | Verde |
|---|---:|---:|---:|
| Erick | 1 | 0 | 0 |
| Ana | 0 | 1 | 0 |
| Carlos | 0 | 0 | 1 |

Em JavaScript, essa representação numérica poderia ser uma lista de listas:

```js
const coresComoNumeros = [
  [1, 0, 0], // Erick: azul
  [0, 1, 0], // Ana: vermelho
  [0, 0, 1]  // Carlos: verde
];
```

Essa matriz numérica é o tipo de informação que pode ser transformada em um Tensor. Assim, o modelo consegue identificar padrões nos dados — por exemplo, relacionar as características de pessoas às suas categorias:

```js
const categorias = [ 
  'Erick', 'premium', 
  'Ana', 'medium', 
  'Carlos', 'basic' 
];
```

A ideia é parecida com traduzir informações do mundo real para uma linguagem que o modelo consegue interpretar: em vez de “azul”, usamos `[1, 0, 0]`; em vez de objetos JavaScript, usamos dados numéricos organizados em tensores.
