A normalização de dados é uma etapa de preparação em que transformamos os valores ou categorias para um formato que o algoritmo consiga interpretar melhor.

No contexto apresentado, temos as categorias:

```js
const categorias = ["premium", "medium", "basico"];
```

Como uma rede neural trabalha com números e cálculos, não basta informar apenas textos como `"premium"` ou `"basico"`. É necessário representar essas categorias de uma forma adequada para o modelo, para que ele consiga aprender a associar os perfis às classificações corretas.

Isso é necessário porque a rede neural recebe dados como entrada, realiza várias conexões e cálculos nas camadas internas e, ao final, produz probabilidades para cada categoria. Por exemplo, ela pode indicar que um perfil tem:

- 78% de chance de ser **Premium**
- 12% de chance de ser **Medium**
- 10% de chance de ser **Basic**

Uma analogia simples: a normalização funciona como traduzir informações para um idioma que a rede neural entende. Nós entendemos rótulos como “Premium”, mas o algoritmo precisa que essas informações estejam preparadas de um modo compatível com seus cálculos.
