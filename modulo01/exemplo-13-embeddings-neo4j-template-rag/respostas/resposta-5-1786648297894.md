**One-hot encoding** é uma técnica usada para transformar categorias em números que uma rede neural consegue processar.

Por exemplo, imagine que temos uma informação de **cor** com três categorias:

- Vermelho
- Verde
- Azul

Em vez de representar essas cores como `1`, `2` e `3`, usamos um vetor com uma posição para cada categoria:

```text
Vermelho → [1, 0, 0]
Verde    → [0, 1, 0]
Azul     → [0, 0, 1]
```

O nome “one-hot” vem justamente disso: em cada vetor, existe apenas um valor “ligado” (`1`) e todos os outros ficam “desligados” (`0`).

Isso é importante porque, em uma rede neural, cada input vira um parâmetro enviado para a primeira camada do modelo. Por exemplo, idade, cor e localização podem ser entradas. Enquanto a idade já é um número, como `25`, categorias como cor ou localização precisam ser convertidas para números antes de entrar na rede.

Usamos one-hot encoding principalmente quando as categorias **não têm uma ordem natural**. Por exemplo:

- Cor: vermelho, verde e azul;
- Cidade: São Paulo, Recife e Curitiba;
- Tipo de produto: livro, roupa e eletrônico;
- Classe que o modelo deve prever: gato, cachorro ou pássaro.

Evite usar números simples como:

```text
Vermelho → 1
Verde    → 2
Azul     → 3
```

Pois isso pode sugerir ao modelo que “azul” é maior ou mais próximo de “verde” do que de “vermelho”. Para cores, cidades ou tipos de produto, essa relação numérica não faz sentido.

Em resumo: **use one-hot encoding para representar categorias sem ordem**, permitindo que a rede neural trate cada opção como uma categoria independente.
