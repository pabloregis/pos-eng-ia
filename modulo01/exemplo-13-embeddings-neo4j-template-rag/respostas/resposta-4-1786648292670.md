Treinar uma rede neural significa ensinar o modelo a encontrar padrões nos dados para que ele consiga fazer previsões depois.

Pense na rede neural como várias “minicalculadoras matemáticas” conectadas. Ela recebe dados de entrada — por exemplo, a **idade**, a **cor** e a **localização** de uma pessoa — e tenta relacionar essas informações à categoria correta daquela pessoa.

No exemplo do contexto, você enviaria para a rede uma lista de pessoas, junto com a categoria à qual cada uma pertence. Antes disso, os dados precisam ser convertidos em tensores e normalizados, geralmente para valores entre `0` e `1`.

Por exemplo, a idade pode ser normalizada assim:

```js
// Para idades entre 25 e 40
// idade 30:
(30 - 25) / (40 - 25) // 0.33

// idade 25:
(25 - 25) / (40 - 25) // 0

// idade 40:
(40 - 25) / (40 - 25) // 1
```

Durante o treinamento, a rede compara o resultado que ela calculou com a categoria que foi informada como correta. A partir disso, ela vai ajustando suas operações matemáticas internas para errar menos nas próximas tentativas.

É parecido com ensinar alguém usando exemplos: você mostra várias pessoas, suas características e suas categorias. Com o tempo, a pessoa aprende os padrões e consegue tentar classificar uma nova pessoa que nunca viu antes.

Assim, depois de treinada, a rede pode receber os dados de uma nova pessoa e determinar em qual categoria ela tem maior probabilidade de estar.
