O TensorFlow.js não entende diretamente objetos JavaScript, strings ou outras estruturas primitivas. Para usá-los em machine learning, é necessário converter os dados em uma estrutura formada apenas por números: um **tensor**.

Por exemplo, considere este array de pessoas:

```js
const pessoas = [
  { nome: "Erick", idade: 30, cor: "azul", localizacao: "São Paulo" },
  { nome: "Ana", idade: 25, cor: "vermelho", localizacao: "Rio" },
  { nome: "Carlos", idade: 40, cor: "verde", localizacao: "Curitiba" }
];
```

Campos como `idade` já são numéricos e podem ser usados diretamente. Porém, campos como `cor`, `nome` e `localizacao` são textos. Uma forma de convertê-los é criar colunas numéricas para cada categoria possível.

Por exemplo, para a propriedade `cor`, existem três valores: `azul`, `vermelho` e `verde`. Podemos representar cada cor usando `1` para a cor ativa e `0` para as demais:

| Pessoa | azul | vermelho | verde |
|---|---:|---:|---:|
| Erick | 1 | 0 | 0 |
| Ana | 0 | 1 | 0 |
| Carlos | 0 | 0 | 1 |

Assim, a informação textual `"azul"` vira `[1, 0, 0]`, `"vermelho"` vira `[0, 1, 0]` e `"verde"` vira `[0, 0, 1]`.

Essa conversão permite transformar objetos JavaScript em dados numéricos que podem ser organizados em tensores. Pense nisso como traduzir características humanas, como cor preferida, para uma linguagem que o modelo consegue processar: números.
