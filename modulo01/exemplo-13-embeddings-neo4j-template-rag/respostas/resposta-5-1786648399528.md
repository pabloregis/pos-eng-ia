Acredito que você se refere a **one-hot encoding** (às vezes chamado informalmente de “hot encoding”).

É uma técnica para transformar categorias em números que uma rede neural consegue usar. Isso é necessário porque modelos trabalham com valores numéricos: eles não entendem diretamente textos como `"vermelho"`, `"azul"` ou `"verde"`.

Por exemplo, para a característica **cor**, podemos representar cada categoria assim:

```text
Vermelho → [1, 0, 0]
Azul     → [0, 1, 0]
Verde    → [0, 0, 1]
```

Cada posição do vetor representa uma categoria. Apenas uma posição recebe `1`, indicando a categoria presente, e todas as outras recebem `0`. Daí vem o nome *one-hot*: “um valor ativado”.

Isso é útil quando uma entrada do modelo é uma **categoria sem ordem natural**, como:

- cor: vermelho, azul, verde;
- localização: São Paulo, Rio de Janeiro, Curitiba;
- tipo de produto: livro, roupa, eletrônico.

No contexto de uma rede neural, cada input vira um parâmetro enviado para a primeira camada do modelo. Então, em vez de enviar a cor como texto, você envia seu vetor numérico. Por exemplo, se uma pessoa tem idade, cor e localização, as categorias de cor e localização podem ser convertidas com one-hot encoding antes de entrarem na rede.

É importante não representar categorias apenas como números simples, por exemplo:

```text
Vermelho → 1
Azul     → 2
Verde    → 3
```

Isso pode fazer o modelo interpretar incorretamente que “verde” é maior ou mais próximo de “azul” do que de “vermelho”. Com one-hot encoding, todas as categorias são tratadas de forma independente.
