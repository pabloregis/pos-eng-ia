O TensorFlow.js não entende diretamente objetos JavaScript, strings ou outras estruturas primitivas como `"azul"` e `"Curitiba"`. Para usá-los em machine learning, é necessário transformar os dados em uma estrutura contendo apenas números: um **tensor**.

Por exemplo, considere este array de pessoas:

```js
const pessoas = [
  { nome: "Erick", idade: 30, cor: "azul", localizacao: "São Paulo" },
  { nome: "Ana", idade: 25, cor: "vermelho", localizacao: "Rio" },
  { nome: "Carlos", idade: 40, cor: "verde", localizacao: "Curitiba" }
];
```

A propriedade `cor` é textual, então não pode ser enviada diretamente para um tensor. Uma forma de convertê-la é criar uma coluna para cada cor possível e marcar com `1` a cor que pertence à pessoa, usando `0` nas demais. Isso é semelhante a responder “sim” ou “não” para cada opção.

| Pessoa | azul | vermelho | verde |
|---|---:|---:|---:|
| Erick | 1 | 0 | 0 |
| Ana | 0 | 1 | 0 |
| Carlos | 0 | 0 | 1 |

Em JavaScript, essa tabela numérica pode ser representada assim:

```js
const coresConvertidas = [
  [1, 0, 0], // Erick: azul
  [0, 1, 0], // Ana: vermelho
  [0, 0, 1]  // Carlos: verde
];
```

Depois dessa conversão, os dados estão prontos para serem usados como tensor. A ideia principal é: antes de trabalhar com TensorFlow.js, transforme cada informação não numérica — como cor, nome ou localização — em números que representem essas categorias.
